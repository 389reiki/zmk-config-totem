# Vorgemerkt für das nächste Keymap-Update

Jede Zeile mit "- " erscheint im Planer unter "Vorgemerkt". Nach dem Update wird die Liste geleert.
- Neue Ebene „System“: Space + Num zusammen halten (rechter Daumen, 36 + 35, ca. 0,2 s). Inhalt = bisherige Sys-Ebene unverändert (Boot/Reset je Hälfte außen, Mac/Win, Bluetooth, USB/BT, BT löschen). Technik: bedingte Ebene, aktiv wenn NAV_HOLD und NUM aktiv.
- Taste 37 halten öffnet künftig die Fenster-Ebene (bisher Sys): links: Hälfte ← / → (1 / 2), Übersicht (3), Füllen (4), zwei Fenster nebeneinander ⧉ ← / → (11 / 12), Mitte (14), Desktop ← / → (22 / 23), vorherige Größe (25); App-Wechsel zurück / vor (10 / 13). Oben/unten entfällt (Ultrawide, nur links/rechts). Mac: Fn+Ctrl-Kürzel als Makro in einem Rutsch, Windows: Win+Pfeil, Win+Tab, Win+Ctrl+Pfeil. Rechte Seite frei.
- Nav: Fenster (6), Füllen (9) und App-Wechsel (22/23) entfallen; App-Wechsel zieht auf die Fenster-Ebene (10/13). Swapper bleibt offen bei 10 (zurück) und 33 (Shift), statt bisher 10–13, 22, 33.
- Basis 32 (⌫, linker Daumen außen): Halten öffnet die Fenster-Ebene statt Wort löschen (tap-preferred, 200 ms; quick-tap für ⌫-Wiederholung bleibt). Taste 37 öffnet die Fenster-Ebene weiterhin. Wort löschen zieht auf Nav 32 (Mac Opt+⌫, Windows Ctrl+⌫), Entf dort entfällt (bleibt per Shift+⌫).
- Maus schneller und mit sanftem Start: Höchsttempo 600 → 1500 (`#define ZMK_POINTING_DEFAULT_MOVE_VAL 1500` vor `pointing.h`), `&mmv { time-to-max-speed-ms = <500>; acceleration-exponent = <2>; }` (vorher 300 / 1). Kurz tippen = kleiner Schritt, halten = schnell. Werte nach dem ersten Test nachjustieren.
- Präzisions-Taste („Sniper“) auf Nav 23 (links, unten, Mittelfinger; frei, nachdem App ⇢ auf die Fenster-Ebene zieht): halten = Maus auf ¼ Tempo. Technik: neue leere Ebene PRECISE (`&mo PRECISE`) und auf `&mmv_input_listener` ein Kind-Knoten `layers = <PRECISE>` mit `&zip_xy_scaler 1 4`. Gleich auf Mac und Windows.
